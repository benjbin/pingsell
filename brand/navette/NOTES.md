# NAVETTE — identité (v1)

**Concept : « la navette fendue ».** Une navette de tissage (ellipse pointue) coupée en deux le long d'une diagonale ; les deux moitiés glissent en sens opposés, comme deux trajets qui se croisent.
- Moitié haute, bleu clair = **l'aller** : le message part vers le client.
- Moitié basse, bleu électrique = **le retour** : il revient chargé de revenu (couleur pleine, plus dense).
- La fente = le fil qui relie la marque au client (la navette noue les fils). L'axe monte à 40° : croissance, décollage (navette spatiale).

**Construction (grille 64).** Arc extérieur : demi-longueur 26, flèche 13,5 (rayon ≈ 31,8). Coupe rectiligne, fente 3,2. Décalage ±4 le long de l'axe. Axe à −40°. Symétrie centrale parfaite : centre optique = centre géométrique.
**Wordmark « navette », en minuscules** : plus amical et plus distinct que les titres de l'app (déjà en capitales) ; les rondeurs du n/a/e font écho à la navette. Lettres géométriques dessinées à la main (hauteur d'x 100, fût 22, traverses 20, dépassement des ronds 2). Détail : **le double t partage une seule barre** (le fil qui lie), et la coupe du **e** suit l'angle de 40° du symbole.

**Couleurs.** Électrique #145CFF · Marine #0B214A (texte) · Clair #4D82FF · Pâle #DCE6FF. Sur fond marine : aller #4D82FF, retour blanc. Sur tuile bleue : pâle + blanc.

**Tailles minimales.** Symbole seul : 16 px (utiliser favicon.svg, tuile, sous 32 px). Logo horizontal : 96 px de large. Zone de protection : la hauteur du « n » tout autour.

**À faire** : utiliser les fichiers SVG fournis ; garder le symbole à gauche du mot ; fond blanc/pâle ou marine/bleu uni.
**À ne pas faire** : écrire « navette » avec une police (toujours le vectoriel) ; redresser ou retourner le symbole ; inverser aller/retour ; ajouter dégradé, ombre ou contour ; poser le logo couleur sur une photo chargée ; passer le mot en capitales dans le logo.
